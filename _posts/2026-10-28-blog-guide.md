> 欢迎来到我的笔记本 🎉 这是一篇置顶的使用指南，教你以后怎么写新笔记。

## 一、新建一篇笔记

在 `_posts/` 目录下新建一个 Markdown 文件，文件名格式**必须**是：

```text
YYYY-MM-DD-标题.md
```

例如：`2026-10-28-my-first-note.md`（文件名建议用英文或拼音，中文标题写在下面配置里）。

## 二、文件开头写元信息（front matter）

```yaml
---
title: 笔记的中文标题
date: 2026-10-28 21:00:00 +0800
categories: [分类1, 分类2]
tags: [标签1, 标签2]
pin: true        # 可选：置顶显示
toc: true        # 可选：显示目录（默认已开启）
---
```

- `categories`：分类，会出现在左侧「分类」页
- `tags`：标签，会出现在左侧「标签」页
- 都可以只填一个

## 三、正文就是普通 Markdown

````markdown
## 二级标题
- 列表项
- **加粗**、*斜体*、`行内代码`

| 表格 | 示例 |
| ---- | ---- |
| A    | 1    |

> 引用文字

```python
# 代码块
print("hello")
```
````

## 四、插入图片

图片放在 `assets/img/` 目录（可按日期建子文件夹），正文里这样引用：

```markdown
![图片说明](/assets/img/20261028/pic.png)
```

## 五、发布

1. 把写好的 `.md` 文件交给智能体，说一声「发布博客」即可；或
2. 自己执行 `git add . && git commit -m "新笔记" && git push`

推送后 GitHub 会自动构建，约 1～2 分钟后刷新 [https://boonvvv.github.io](https://boonvvv.github.io) 就能看到。

## 六、写作建议

- 一篇笔记一个主题，标题写清楚日期或主题，方便日后搜索
- 顶部搜索框支持全文搜索，笔记多了也不怕找不到
- 笔记是公开的，**不要记录密码、证件号等隐私信息**
